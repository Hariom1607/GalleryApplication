# Gallery Application

A simple iOS Gallery Application developed using UIKit and MVVM Architecture.

## Features

- Google Sign-In Authentication
- Online Gallery using Picsum API
- Pagination
- Offline Support
- Core Data Persistence
- Profile Screen
- Logout

## Architecture

- MVVM
- Singleton Pattern
- URLSession Networking
- Core Data
- UIKit

## Libraries

- Firebase
- Google Sign-In
- Kingfisher

## Screens

- Login
- Gallery
- Profile

## Offline Support

- Gallery metadata is stored using Core Data.
- Images are cached locally for offline viewing.

## Requirements

- Xcode 16
- iOS 18+

## Installation

```bash
git clone <repository-url>
cd GalleryApplication
pod install
open GalleryApplication.xcworkspace
```
